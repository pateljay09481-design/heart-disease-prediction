This project predicts the risk of heart disease using KNN  machine learning model.

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Machine Learning Model

K-Nearest Neighbors (KNN)



## Features

The application takes the following inputs:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope
